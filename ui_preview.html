🏁 Quick Start Guide

1. Basic Setup
Ensure Python 3.11+ is installed with core dependencies (torch, transformers, pyyaml).
2. Try the Compiler
Test the Molly compiler interface: mollyc --help
3. Convert a Mesh
Use mesh2brick to convert any 3D file to LEGO: python -m mesh2brick input.obj output.ldr
4. Advanced Features
Install Blender (bpy) for rendering and Gurobi for optimization (free academic license available).
